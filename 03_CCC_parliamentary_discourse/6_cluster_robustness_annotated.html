Input and corpus version

The main analyses use the climate-policy corpus constructed in “1_full corpus building_final.Rmd”. In the analysis files, ‘df_climate’ refers to the main climate-policy corpus unless otherwise stated. A stricter matching strategy using word boundaries is used only for validation or robustness checks.

Robustness specification

This file uses a stricter matching strategy and/or stricter dictionary specification. These results are used as robustness checks and do not replace the main analysis.

Workflow note

This document examines the robustness of the policy-theme salience results at the level of the six CCC policy clusters. It reconstructs the speech corpus, applies cluster-specific keyword sets, checks selected matches, computes cluster-level counts and period proportions, and visualises the patterns. Cluster matches indicate thematic references, which need not be explicit references to the CCC. All original code is preserved.

# Extract and standardise text and metadata from the source records for the subsequent analysis.

parse_one_xml <- function(file_path) {
 doc <- read_xml(file_path)
 xml_ns_strip(doc)
 
 if (length(xml_find_all(doc, ".//paragraphe")) > 0) {
  nodes <- xml_find_all(doc, ".//paragraphe")
  tag_used <- "paragraphe"
 } else if (length(xml_find_all(doc, ".//para")) > 0) {
  nodes <- xml_find_all(doc, ".//para")
  tag_used <- "para"
 } else if (length(xml_find_all(doc, ".//texte")) > 0) {
  nodes <- xml_find_all(doc, ".//texte")
  tag_used <- "texte"
 } else {
  return(tibble(
         file = basename(file_path),
         tag_used = NA_character_,
         speech_text = NA_character_
         ))
 }
 
tibble(
 file = basename(file_path),
 tag_used = tag_used,
 speech_text = xml_text(nodes)
) %>%
 mutate(
  speech_text = str_remove_all(speech_text, "\\d+"),
  speech_text = str_remove_all(speech_text, "\\([^\\)]+\\)"),
  speech_text = str_remove_all(speech_text, "La parole est à.*?(\\.|$)"),
  speech_text = str_remove_all(speech_text, "La séance est.*?(\\.|$)"),
  speech_text = str_squish(speech_text)
 ) %>%
 filter(!is.na(speech_text), speech_text != "")
}

 mutate(
  cluster = factor(
   cluster,
   levels = c(
    "consumption",
    "production",
    "mobility",
    "housing",
    "food",
    "constitution"
   )
  ),
   period = factor(
    period,
    levels = c(
     "pre",
     "transition",
     "post"
    )
   )
 ) %>%
 arrange(cluster, period) %>%
 mutate(
  proportion =
   round(proportion, 2)
 )

view(cluster_prop)
